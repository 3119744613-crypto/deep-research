## 实现缺陷与修复

- 首次服务测试 14 通过、4 失败：macOS `setrlimit` 拒绝 DATA/AS 限制，所有解析子进程提前退出。单独复现后修复为 Linux AS 硬限制 + 跨平台父进程 RSS 监控；macOS 存在 20ms 采样间隔。随后服务 23 项通过。psutil 首次安装 DNS 失败，网络修复后安装成功。
- 独立审查复现 PATCH/run 竞态：PATCH 读旧 ready 后覆盖 running，模型已经执行但任务回到 ready。新增并发回归先失败，再用 SQLite 条件事务保护 PATCH/run/cancel；服务 24 项通过。
- 独立审查复现 inference.quote 可伪造原文。新增反例先出现 `DID NOT RAISE`；修复为所有非空 quote 均须匹配对应来源连续原文，fact 另要求非空，inference 可空且始终待验证。引擎/提供商 60 项测试通过。
- 统一 Ruff 首轮发现 import 顺序、嵌套 async with、无用 lambda 与一个未格式化文件；修复后默认规则和格式检查通过，没有降低检查规则。
